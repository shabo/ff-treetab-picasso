# Security Policy

## Supported versions

Only the latest version published on addons.mozilla.org gets security fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Report privately through GitHub:
<https://github.com/shabo/ff-treetab-picasso/security/advisories/new>

Include the add-on version, Firefox version, Tree Style Tab version, and steps to reproduce.
You get a first answer within 7 days.

## Scope

The add-on has no network access and collects no data. Relevant reports include: CSS or script
injection through emoji input, messages from other add-ons that change markers, and permission
misuse.
